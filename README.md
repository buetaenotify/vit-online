# วิทย์ออนไลน์ · โรงเรียนบ้านบือแต

แอปสำหรับติดตั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์ (PWA) ของระบบเว็บการศึกษา **วิทย์ออนไลน์**
ตัวระบบหลักทำงานบน Google Sheets + Apps Script ส่วนแอปนี้เป็น "เปลือก" ที่มีไอคอน และเปิดเว็บแอปเต็มจอ

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแอป: หน้าจอโหลด + เปิดเว็บแอปเต็มจอ + ปุ่มติดตั้ง |
| `config.js` | **ที่เดียวที่ต้องแก้** — ใส่ลิงก์เว็บแอป Apps Script |
| `manifest.webmanifest` | ชื่อแอป สี และไอคอน |
| `sw.js` | ทำให้ติดตั้งได้และเปิดเร็วขึ้น |
| `icons/` | ไอคอนทุกขนาด |

## วิธีขึ้น GitHub Pages (ทำครั้งเดียว)

1. สร้าง repository ใหม่ใน GitHub เช่น `vit-online` (เลือก **Public**)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons`) ขึ้น repository
3. เปิดไฟล์ `config.js` → กดดินสอแก้ไข → วางลิงก์เว็บแอป (ลงท้ายด้วย `/exec`) → Commit
4. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
5. รอ 1–2 นาที จะได้ลิงก์แอป เช่น `https://ชื่อผู้ใช้.github.io/vit-online/`

## วิธีติดตั้งแอปบนเครื่อง

- **Android / Chrome บนคอมพิวเตอร์**: เปิดลิงก์แอป → กดปุ่ม **📲 ติดตั้ง** ที่ขึ้นด้านล่าง (หรือเมนู ⋮ → ติดตั้งแอป)
- **iPhone / iPad**: เปิดด้วย **Safari** → แตะปุ่ม **แชร์ ⬆️** → **เพิ่มไปยังหน้าจอโฮม**

## ให้โลโก้ในระบบตรงกับไอคอนแอป

ในชีต **ตั้งค่า** แถว `ลิงก์โลโก้` ใส่
`https://ชื่อผู้ใช้.github.io/vit-online/icons/icon-192.png`

## หมายเหตุ

- ต้องเชื่อมต่ออินเทอร์เน็ต เพราะข้อมูลอยู่ใน Google Sheets
- ฝั่ง Apps Script ต้อง **ทำให้ใช้งานได้เป็นเว็บแอป** แบบ "ผู้มีสิทธิ์เข้าถึง: ทุกคน"
- เมื่ออัปเดตโค้ด Apps Script ให้แก้การทำให้ใช้งานได้เดิมเป็น **เวอร์ชันใหม่** ลิงก์ `/exec` จะคงเดิม ไม่ต้องแก้ `config.js`
- ถ้าเปลี่ยนไอคอน ให้แก้เลข `CACHE` ใน `sw.js` (เช่น `v1` → `v2`) เพื่อให้เครื่องที่ติดตั้งแล้วโหลดไอคอนใหม่
